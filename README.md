# Esteira de pedidos de cozinha
Sistema de Esteira de Pedidos de Cozinha (Kitchen Flow) desenvolvido como protótipo de um KDS (Kitchen Display System) para gerenciamento de pedidos em uma cozinha de restaurante.
## Sobre o projeto
O Kitchen flow tem como objetivo organizar os pedidos recebidos do salão em uma esteira de preparo, respeitando a ordem de chegada das comandas.

O sistema permite armazenar os dados detalhados de cada pedido, controlar o fluxo das comandas durante o preparo e manter um histórico cronológico das operações, possibilitando que os chefs desfaçam determinadas ações, como a retirada acidental de uma comanda da bancada.
## Objetivo
O projeto foi desenvolvido para aplicar, na prática, conceitos de Modelagem e Manipulação de Coleções em Python, utilizando principalmente Listas, Tuplas e Dicionários.

A proposta é simular o funcionamento básico de um sistema utilizado em cozinhas profissionais para organizar e controlar pedidos.
## Funcionalidades
O sistema deve permitir:

• Adicionar um novo prato ao cardápio caso ele ainda não esteja cadastrado;

• Realizar o cadastro de uma nova comanda;

• Iniciar o preparo da próxima comanda;

• Desfazer a última ação registrada no histórico;

• Exibir o estado atual do sistema.
